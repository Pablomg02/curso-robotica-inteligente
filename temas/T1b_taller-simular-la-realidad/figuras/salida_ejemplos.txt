2. Densidad espectral del ruido blanco del giróscopo de Gazebo
==============================================================================
sigma = 0.0008726646 rad/s = 0.050 °/s por muestra a fs = 250 Hz
PSD unilateral plana: S = 2·sigma²/fs = 6.092e-09 (rad/s)²/Hz
comprobación: integrar S de 0 a fs/2 da S·fs/2 = 7.615e-07 = sigma² = 7.615e-07
densidad de ruido sqrt(S) = 7.805e-05 rad/s/√Hz = 0.00447 °/s/√Hz
lo que registra PX4 (sensor_combined) es la media de dos muestras seguidas (trapecio de Integrator.hpp):
  H(f) = (1 + exp(-j 2 pi f/fs))/2  ->  |H(f)|² = cos²(pi f/fs): 1 en 0 Hz, 0,5 en fs/4, 0 en Nyquist
  f =  10.0 Hz: cos² = 0.984 -> S0·cos² = 6.00e-09
  f =  30.0 Hz: cos² = 0.864 -> S0·cos² = 5.27e-09
  f =  62.5 Hz: cos² = 0.500 -> S0·cos² = 3.05e-09
  f = 100.0 Hz: cos² = 0.095 -> S0·cos² = 5.82e-10
  f = 125.0 Hz: cos² = 0.000 -> S0·cos² = 2.28e-41
  varianza de la media de dos muestras: sigma²/2 = 3.808e-07 (= integral de S0·cos² de 0 a fs/2 = S0·fs/4 = 3.808e-07)
medida en el SITL, banda 20-50 Hz: 5.760e-09; cos² medio 0.810; corregida 7.012e-09 = +15 % sobre la teórica
